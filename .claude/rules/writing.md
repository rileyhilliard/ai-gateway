# Writing

Load `ce:writer`. Use the Contributor persona (`references/contributor.md`) for commit messages and the Engineer persona (`references/engineer.md`) for READMEs and plans, and check drafts against `references/forbidden-patterns.md`.

- Plans and READMEs are read on a shared screen. Keep them short and lead with what works and how to run it.
- Phase commits are `phase N: <capability that now works>`. The body, if any, says why.
- Only document commands that exist in this repo and work as written.
